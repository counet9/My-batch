MON BATCH V10 — INSTALLATION

Cette version rééquilibre les quantités de légumes et d'aromates dans le catalogue.
Les 19 recettes Basta conservent leurs ingrédients et leurs étapes de référence ; seules les quantités trop abondantes ont été ajustées, avec les féculents gardés aux portions convenues.
Les 31 recettes originales Mon Batch ont aussi été auditées.

RÈGLE DE CALCUL
Chaque fiche du catalogue est pour 1 personne et 1 dîner.
Liste de courses = quantité de base × nombre de personnes × nombre de jours.
Aucun doublement caché.
Exemple poulet miso, 2 personnes × 3 jours : 780 g poulet, 900 g brocoli, 750 g riz cru et 6 gousses d'ail.

INSTALLATION
1. Décompresse cette archive.
2. Remplace les fichiers à la racine du dépôt GitHub My-batch par les fichiers fournis : index.html, manifest.json, service-worker.js et icon.svg.
   README.txt est uniquement explicatif et peut être conservé à côté.
3. Fais un commit GitHub et laisse GitHub Pages publier la mise à jour.
4. Ouvre Safari sur https://counet9.github.io/My-batch/ et actualise. Vérifie l'étiquette V10 dans l'en-tête.
5. Ferme puis relance l'icône installée sur l'écran d'accueil.

Les recettes personnelles que tu ajoutes restent enregistrées sur ton appareil. Leur formulaire est prévu pour 4 portions ; l'application divise donc les quantités par 4 pour les remettre à l'échelle choisie.
Les prix et valeurs nutritionnelles sont des estimations indicatives, pas des objectifs.
